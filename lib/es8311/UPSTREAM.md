# ES8311 codec driver

Unmodified es8311.c, es8311.h and es8311_reg.h from Waveshare's ESP32-S3-Touch-AMOLED-1.75C repository, examples/arduino/examples/07_ES8311, commit 6d19f7e16fb9a3be219e9eed43ca9eb56c88d01c.

Copyright 2015-2022 Espressif Systems (Shanghai) CO LTD. Apache-2.0; see LICENSE. Waveshare's Arduino HAL adaptation shares the board's existing I2C bus. Only the Waveshare profile uses this dependency. Dragon Detector supplies its own MIT PCM synthesis and scheduling; microphone input is not configured.

Source: https://github.com/waveshareteam/ESP32-S3-Touch-AMOLED-1.75C
