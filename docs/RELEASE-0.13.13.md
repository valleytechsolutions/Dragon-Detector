# Dragon Detector 0.13.13

The project now uses a simple orange Dragon Ball with the red/black BWM emblem replacing the star. The same artwork appears on GitHub, the web flasher, the original three radar themes and every board's startup animation.

- A clean black startup screen fades in the new transparent logo. The former VTS startup is replaced on all five profiles.
- The Dragon Ball watch shows a large, unobscured emblem, 24-hour time, date and a moving seconds marker. Selecting the Dragon Ball theme selects its matching watch on full boards. Lite includes a compact version with its existing BOOT controls.
- Existing theme and watch IDs remain stable. The 31-theme / 29-watch catalog, clock synchronization, locksport tools and other features remain available.
- One compressed native-size logo is reused by startup and the watch. The 21% application-slot reserve guard stays enabled on all five builds.

Keep USB connected after web flashing so the installer can set and verify the date, time and timezone. M5Burner users should connect Detector tools in the web flasher after burning; M5Burner itself does not perform clock synchronization.
