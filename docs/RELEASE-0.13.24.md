# Dragon Detector 0.13.24

Adds **MuldersreVenge**, a simple black-and-brass theme using the supplied original emblem. It includes matching menus, radar styling and a digital clock on all eight current board profiles.

Choose **MuldersreVenge** in the device theme settings or the web flasher's radar appearance selector. Lite uses its existing BOOT theme control. Artwork is embedded; no SD asset download is required.

Existing theme IDs, detection, controls, scanning, storage and radio features are unchanged. The web USB tools recognize the appended theme ID and require 0.13.24 before selecting it.

Validation: native LVGL previews at 240, 360, 466 and 480 pixels; logo decoder/CRC checks; web tests; all eight firmware builds and flash-layout checks. This theme has not been tested on physical hardware. Existing board beta/experimental status still applies.
