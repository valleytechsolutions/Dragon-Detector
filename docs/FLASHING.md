# Flashing Dragon Detector

## 1. Match the board before downloading

| Board | File | Address |
|---|---|---|
| Spotpear/Guition JC3636W518, 360×360 | [v0.1.1 complete BIN](../hardware/spotpear/firmware/Dragon-Detector-0.1.1-ESP32S3-JC3636W518-0x0.bin) | `0x0` |
| M5Stack StopWatch C152, 466×466 | [v0.2.0 factory BIN](../hardware/m5stack-stopwatch/release/Dragon-Detector-StopWatch-v0.2.0-factory-0x0.bin) | `0x0` |
| Existing StopWatch Dragon Detector with the same partition layout | [v0.2.0 update BIN](../hardware/m5stack-stopwatch/release/Dragon-Detector-StopWatch-v0.2.0-update-0x0.bin) | `0x0` |

The StopWatch factory BIN is 16,777,216 bytes and replaces internal files and settings. The update BIN is 1,683,648 bytes and preserves the filesystem only on this exact StopWatch layout; it resets NVS preferences. Use factory for initial installation. The Spotpear full BIN is 1,572,752 bytes. Neither Spotpear image nor StopWatch image belongs on the other device.

## 2. Download the files

Download this repository with **Code → Download ZIP**, extract it, then open a terminal in the extracted `DragonBall-Z-Radar` folder. Alternatively, download the one BIN through GitHub's **Download raw file** button. The commands below assume the whole repository was extracted; if you downloaded just a BIN, replace its path with your downloaded file's path.

## 3. Install the flashing tools

Install Python 3.11 or newer from [python.org](https://www.python.org/downloads/). On Windows, open PowerShell and run:

```powershell
py -m pip install "esptool==5.4.0" pyserial
py -m serial.tools.list_ports
```

On macOS/Linux use `python3` instead of `py`. Connect through a USB data cable. Note the port that appears when the board is connected, such as `COM4`, `/dev/ttyACM0` or `/dev/cu.usbmodem...`. Close serial monitors and other flashing programs before proceeding. COM4 below is an example, not a guaranteed port.

## 4. Optional: save your original firmware

Both supported configurations use 16 MB flash. This command reads the full device without modifying it:

```powershell
py -m esptool --chip esp32s3 --port COM4 read-flash 0x0 0x1000000 original-device-backup.bin
```

Keep this backup outside the repository; it can contain your private files/settings. A full backup can be restored to the same device at `0x0` using `write-flash`.

## 5. Check the download

```powershell
Get-FileHash ./hardware/m5stack-stopwatch/release/Dragon-Detector-StopWatch-v0.2.0-factory-0x0.bin -Algorithm SHA256
```

Compare with [the repository checksums](../FIRMWARE-SHA256SUMS.txt). For Spotpear substitute its file path. On macOS use `shasum -a 256 FILE`; on Linux use `sha256sum FILE`. Do not flash a download with a mismatched checksum.

## 6. Flash the matching complete image

### M5Stack StopWatch

```powershell
py -m esptool --chip esp32s3 --port COM4 --baud 921600 --after watchdog-reset write-flash 0x0 hardware/m5stack-stopwatch/release/Dragon-Detector-StopWatch-v0.2.0-factory-0x0.bin
```

### Spotpear JC3636W518

```powershell
py -m esptool --chip esp32s3 --port COM4 --baud 921600 write-flash 0x0 hardware/spotpear/firmware/Dragon-Detector-0.1.1-ESP32S3-JC3636W518-0x0.bin
```

Wait for verification and reset to finish. Do not disconnect during writing. A separate full erase is not required. The files above are merged images: do not place them at `0x10000` and do not separately flash a bootloader alongside them.

For StopWatch download mode: with USB connected, hold the **power button for about two seconds** until the green LED lights, then release. See [M5Stack's official instructions](https://docs.m5stack.com/en/core/StopWatch).

## 7. First boot

The VTS boot logo should lead to a green radar. Give scans several seconds to collect contacts. On StopWatch, yellow returns to radar and blue opens tools. On Spotpear, swipe upward from the radar's bottom edge. Scrolling a list should keep it open. Follow the [user guide](USER-GUIDE.md) for logs, badges and radio controls.

## Updating an existing StopWatch

Only when it already uses this partition layout, replace `factory` with `update` in the StopWatch flash command. Stored badges/logs survive, but preferences reset. For developers, the application generated by PlatformIO is an **app-only** file at `.pio/build/stopwatch/firmware.bin`; its address is `0x10000`. It is not an initial-install image. Never infer an image's address from its `.bin` extension alone.

## Troubleshooting

| Symptom | Action |
|---|---|
| No port | Try a known data cable and another USB port. Check the OS device list and the exact board's driver guidance. |
| Port busy / access denied | Close Arduino, PlatformIO monitors, browser importers, M5Burner and other serial applications. On Linux check serial-device permissions. |
| Cannot connect | Follow the manufacturer's download-mode procedure. On boards with BOOT/RESET, hold BOOT while resetting, then release it and retry. |
| Write fails at high speed | Retry with `--baud 115200`; keep the cable short and power stable. |
| StopWatch does not restart | Use the supplied `--after watchdog-reset` command; power-cycle if necessary. |
| Blank screen, wrong colors or wrong touch | Check the board label and BIN choice first. The current StopWatch release corrects RGB565 byte order. Report the filename and symptoms if it persists. |
| StopWatch storage mount error | Back up any needed data and install the factory image; an app-only flash does not create its filesystem. |
| Sparse contacts | Check that radio scanning is enabled. Channel lock pauses BLE, and scanning alternates radios/channels. Silent devices cannot be discovered. |

Reference: [Espressif esptool basic commands](https://docs.espressif.com/projects/esptool/en/latest/esp32s3/esptool/basic-commands.html). For M5Burner submission, see [its separate guide](../publishing/m5burner-stopwatch/SUBMISSION.md).
