Install the T5-E1 beta

  1. Download and unzip the beta package above. Open the official Tuya tyutool.
  2. Connect a USB data cable. The CH342 bridge exposes a flashing UART and a logging UART. Close other programs using these ports.
  3. Preserve the original flash using the tool's Read function where supported. Keep the Waveshare factory recovery/demo available. Avoid a full-chip erase that removes RF calibration.
  4. Choose t5ai / T5, 921600 baud, and dragon_detector_QIO_0.1.0.bin, at 0x00000000. Start flashing and follow the tool's reset prompts. Use the board's RESET button if it waits for the bootloader. Check the other UART if it cannot connect.
  5. Reset after the write completes. Open the logging UART at 115200, 8-N-1. Check the Dragon Detector startup message and radio initialization results.

The current Dragon Detector browser USB installer supports ESP32 hardware. Install this T5-E1 beta with Tuya's tool. No Tuya account pairing or cloud credentials are required by this application. See the official Tuya flashing reference.

First board test

Confirm the screen and touch, increasing Wi-Fi/BLE counters, all four filters, contact evidence details, and pause/resume. Contacts expire after 30 seconds. Save serial errors or restart logs during a 30-minute test for troubleshooting.

This initial port has a compact contact interface. Full ESP32 radar themes, GPS, SD logging, clock/watch features and raw Wi-Fi frame analytics are not included. BLE vendor-address hints remain disabled pending validation of the T5 adapter's address ordering. Signals and vendor matches are indicators, not proof of a device's purpose or activity.
