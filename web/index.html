Connection & recovery

Close other serial monitors before connecting. If the port does not appear, hold BOOT, tap RESET, release BOOT, then reconnect. Select the matching USB port. A first installation initializes the badge filesystem; back up existing firmware before replacing it. Use Update only with this board's existing 0.3.x partition layout. KNOW WHAT YOU’RE SEEING

Evidence, at a glance.

Looks for Flock/ALPR-related signatures, Axon identifiers, Find My accessories, Samsung SmartTags, Flipper, Nyanbox, Biscuit and other named candidates. A match does not establish malicious intent, recording state, or a device's owner.

AirTag and Biscuit Pro/Ultra models cannot always be distinguished. RSSI is signal strength, not distance; the radar angle is decorative. Silent radios and 5/6 GHz devices remain outside coverage.
