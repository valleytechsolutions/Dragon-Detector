No port listed? ESP32 drivers · Connection & recovery

Connection & recovery
No USB port appears
Try a known data cable and a direct USB port on the computer. Check Device Manager on Windows. Install the driver matching the USB bridge below, reconnect the board, and select its port. Native ESP32-S3 USB usually uses the operating system's built-in driver.
Port is busy or access is denied
Close Arduino, PlatformIO, other browser flashers and serial monitors. Disconnect Badge Studio before installing. Reload the direct flasher if the browser blocked serial access.
Failed to initialize / stuck connecting
On Waveshare boards with BOOT and RESET: hold BOOT, tap RESET, release BOOT, then choose the reappearing port and retry Install. The AMOLED 1.43C has no RESET button: switch it off, then hold BOOT while plugging USB back in. For XIAO, follow its board's BOOT/download procedure. On StopWatch, hold power for about two seconds until the green LED lights, then release. Leave buttons untouched while writing.
Download failed or writing stopped
Check the internet connection, keep the USB cable connected, and retry with the exact same board profile. The installer downloads the complete set before erasing. If writing was interrupted, use BOOT/RESET to re-enter download mode; keep the same installation type.
Install finished, but the display is blank
Press RESET once or restart the board without holding BOOT. Recheck the exact display model: an ESP32-S3 chip match does not verify display wiring. Fresh installation is required when replacing a factory demo or incompatible firmware; it erases saved files. For StopWatch, close USB tools, unplug USB, double-press power to turn it off, wait five seconds, then press power once.
Firmware installed, clock not confirmed
This is a separate setup step. Reconnect the running board and use Sync device clock. You do not need to erase or reinstall. If the board still has no display, check its model and restart it first.
